# 一日の栄養ゲージ

ホームと「栄養」画面に、選んだ日付の記録済み栄養量と個人の目標を比較するゲージを表示します。

1. 設定の「一日の栄養目標」に比較したい目標を入力して保存します。目標は初期設定していません。空欄の栄養素は比較しません。
2. 以前の分析結果には数値がないため、食事の「もう一度確認する」で再分析するか、栄養量を手入力します。
3. 「食べた量・栄養量を確認して補正」を開き、写真に写る全量の栄養値と、食べた割合を確認します。写真の半分を食べた場合は50%、全量は100%です。
4. 「量を確認して保存」で補正値と割合を保存します。包装の栄養表示などを使って数値を修正できます。おやつや飲みものもこの欄で補正できます。

炭水化物・たんぱく質・脂質はg、ビタミンC・カルシウムはmgで計算します。ビタミンとミネラル全体を単一の達成率にはしません。これらの分類には異なる栄養素が含まれ、それぞれに基準があります。目標量の参考：https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/kenkou/eiyou/syokuji_kijyun.html

計算は「写真の全量の栄養値 × 食べた割合」を記録ごとに行い、その日の記録だけを合計します。AIの推定値より、保存した補正値を優先します。再分析でも補正値は保持します。写真の追加・削除で分析を取り消す際には対応する補正値も取り消します。

未計算の項目は0に置き換えず、記録の一部だけが合計されていることを表示します。目標を超えた場合も実際の割合は表示し、ゲージの長さだけ100%に収めます。記録のない日は未計算です。ゲージは目標に対する比較であり、個人の必要量や栄養不足の診断ではありません。

写真とプロフィールからAIが充足度を直接返していた旧PUT APIは復活させていません。現在の認証済みPOST APIに栄養量の概算を追加し、目標量・割合・日付ごとの合計はアプリ内で計算します。個人の目標量はAnthropicへ送信しません。
